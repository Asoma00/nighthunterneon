# art/ — внешняя графика

Любой PNG, положенный сюда, **заменяет процедурную отрисовку** из `pixel.gd`.
Файла нет — игра рисует кодом, как раньше. Смешивать можно: перевели героев, остальное осталось кодом.

## Формат спрайтов

`art/sprites/<key>.png`, где `<key>` — ключ из `Pixel.SPECS` (`rin`, `goblin`, `lich`, `chest`…).

- ширина файла = ширина кадра × число кадров
- высота = высота кадра × 1..3
- полосы сверху вниз: **base** (обычный спрайт, освещается), **emit** (неон, светится сам), **flash** (белая вспышка при попадании)
- 1 полоса — emit пустой, flash считается силуэтом автоматически
- 2 полосы — flash считается силуэтом автоматически
- 3 полосы — всё берётся из файла

Размеры кадров — в `Pixel.SPECS`, они же в шаблонах `art_ref/`. Рисуйте в тех же пикселях:
масштаб в игре уже учтён (`Pixel.PX = 3`).

Пример: `rin` — 48×60, 35 кадров → файл 1680×180.

## Иконки

`art/icons/<id>.png` — 36×36, прозрачный фон. Список id — `Icons.IDS`.

## Пол

`art/ground/base.png` и `art/ground/emit.png` — 128×128, тайлятся бесшовно.

## 3D-материалы

`art/surface/<kind>.png` — 16×16, тайлится: `panel`, `brick`, `tile`, `wood`.

## Как проверить

`godot --headless --path . --script tools/bake_art.gd` заново выгружает шаблоны в `art_ref/`.
Папка `art_ref/` помечена `.gdignore` и в сборку не попадает.
