# Ночь охотника: Неон — версия 0.14.8

**Скачать для любого устройства:** https://asoma00.github.io/nighthunterneon/download/
(Windows, Steam Deck / Linux, Android, а на iPhone — игра прямо в Safari)

Игра работает в браузере на iPhone, установка с ПК не нужна. Здесь же лежит сборка .ipa для iOS.

## Как играть на iPhone

1. Откройте в Safari на iPhone адрес **https://asoma00.github.io/nighthunterneon/**
   2. Нажмите «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».
3. Запускайте игру с иконки на экране «Домой». Она открывается на весь экран, как обычное приложение.
   Игра поворачивается вместе с телефоном. Звук включается после первого касания экрана.

Обновления приходят сами: GitHub пересобирает игру при каждой загрузке новых файлов.
Сохранения хранятся в телефоне. Не удаляйте «Данные сайтов» для github.io в настройках Safari.

## Первая настройка (один раз)

1. Репозиторий должен быть **публичным**. Бесплатный GitHub Pages работает только для публичных репозиториев.
2. Загрузите в репозиторий все файлы и папки, включая скрытую `.github`.
3. Откройте **Settings → Pages**. В «Build and deployment» → «Source» выберите **GitHub Actions**.
4. Откройте вкладку **Actions** → «Веб-версия для iPhone (GitHub Pages)» → **Run workflow**.
   Через 3–5 минут появится зелёная галочка, и игра станет доступна по адресу выше.

## Сборка .ipa (необязательно)

Actions → «Сборка iOS (IPA)» → Run workflow. Артефакт с .ipa ставится через Sideloadly с компьютера.

## Автообновление

Игра сама проверяет обновления при запуске и раз в 3 минуты, если есть сеть.
Новая версия скачивается в фоне (~1 МБ), а в меню или убежище игра сразу перезапускается уже обновлённой.
Версии на ПК, Steam Deck и Android ставить заново не нужно. Веб-версия на iPhone просто перезагружается.
Номер сборки показан в левом нижнем углу главного меню.
